# risen_universalis_v1: граница пакета и дымовой прогон

Дата: 11 октября 2026. Это не отчёт о выполненном исследовании Risen Universalis. В репозитории не было описания такого исследования, датасета или результата, и этот документ их не изобретает. Пакет — отдельный адаптер. Он не переделывает `synthetic_causal_v1`, `afterlife_seed_v1` и `tabular_classification_v1`.

## Что считает дым

Дымовой прогон берёт две заранее объявленные целые пары и считает контраст `paired_difference`: `score_a - score_b` по каждой строке. Вторая программа считает ту же величину другой формулой на тех же байтах. Это independent reanalysis. Контраст `sum_of_scores` замораживается как конкурирующий эксперимент и не исполняется. Среднее двух разностей на этих строках — арифметика фикстуры. Claim остаётся `inconclusive` / `exploratory`. Потолок ядра не даёт confirmatory: нет оценки эффекта для популяции, допущения не отмечены как выполненные, интервал не заявлен. `scientific_validity` остаётся `not_assessed`. Одобрение reviewer не создаётся.

Определения зафиксированы в пакете до результатов:

- exploratory result описывает объявленный discovery split и не является подтверждением;
- confirmatory result требовал бы заранее не виденный holdout или новые данные, полный отчёт и потолок ядра; дым этому не удовлетворяет;
- independent reanalysis — вторая реализация с другим digest исходника на тех же raw bytes;
- replication — новая выборка или новые данные. Повтор того же кода — `reproduce`, не replication и не evidence.

## Профиль исполнения

Новое исследование на этом пакете принимает только `uv_locked_python_v2`. `trusted_local_python_v1` отвергается при проверке параметров и при привязке: манифест не объявляет его, а окружение v1 не является closure v2. Три прежних пакета остаются на v1. v2 — гигиена окружения и воспроизводимость, не sandbox. Запись local runner: `os_isolation=none`, `sandbox=false`, `network_enforcement=not_enforced`. Код исполнителя работает от того же пользователя ОС и теоретически может читать Store. Это по-прежнему блокирует утверждение «исполнитель физически не мог прочитать данные reviewer или Store».

`cycle step` по-прежнему запускает локальный runner. Для job v2 это `execution.dispatch_v2`, не контейнер. Контейнерный backend (`--network none`, `--read-only`, allowlist mount) существует и не является исполнителем всего цикла.

Если более поздняя версия запишет вызов модели, поля наблюдения (ревизия модели, tokenizer, CUDA, драйвер, GPU, dtype, движок, семплирование, digest шаблона, seed, длина контекста, provider, `model_id`, сырой запрос и ответ, usage) — это наблюдённое исполнение, не обещание точного воспроизведения. Один и тот же `model_id` у внешнего API позже может означать другой backend. Дым эти поля пишет как null: GPU и сетевого API не было.

## Контрольные точки оператора

`episteme checkpoint --root <store>` печатает один digest и не пишет его в store. Совпадение с `--expect` не научный успех. Несовпадение значит, что история изменилась или была переписана; само по себе это не научный провал и не научный успех.

Дым пишет четыре файла рядом со store, не внутри него (`<root>-checkpoints/`):

1. `question_frozen` — после ResearchQuestion и ExplanationSet. Гипотезы после этого не переписываются молча.
2. `protocol_before_expensive_run` — после заморозки протокола и выбора эксперимента, до запусков. Дым дешёвый. Перед дорогим запуском нужно отдельное человеческое одобрение. Файл таким одобрением не является.
3. `claim_ready_for_human_review` — после claim и `review.assign`. Review остаётся человеческим. Одобрение не выставляется.
4. `mechanical_package_not_a_scientific_release` — после `episteme` package / `write_package`. Каталог не научная публикация и не подача.

Порядок для человека:

```powershell
$env:PYTHONPATH = "src"
python examples/risen_universalis_v1/smoke.py --root .research/risen-universalis-smoke
uv run episteme checkpoint --root .research/risen-universalis-smoke --expect <digest из файла>
```

Команда без `--expect` только показывает digest. Хранить его нужно вне store. Повторный запуск требует пустой каталог `--root`.

## Что сознательно не сделано

Настоящее исследование Risen Universalis не начато. Внешние LLM и GPU не вызываются. A-20 (починка повреждённого CAS) и A-21 (каталог snapshot как `--root` и незавершённый restore) остаются открытыми. Контейнер не подставляется вместо локального runner.
